# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выходят только для последней минорной версии 1.x. Обновляйтесь до неё: внутри
мажорной версии изменения обратно совместимы.

| Версия        | Поддержка |
| ------------- | --------- |
| последняя 1.x | да        |
| старше        | нет       |
| 0.x           | нет       |

## Что считается уязвимостью

Пакет стоит на пути телеметрии из браузера в Grafana, поэтому уязвимостью считаются и утечки данных, а не
только исполнение чужого кода:

- токены, идентификаторы или другие персональные данные уходят в Grafana, хотя README обещает их вычищать
  (URL страницы, атрибуты событий, файлы в стектрейсах);
- пакет исполняет или внедряет код из биконов, меток или DOM;
- собранный бандл содержит что-то, чего нет в исходниках и зависимостях.

Уязвимости самого Faro сообщайте в [grafana/faro-web-sdk](https://github.com/grafana/faro-web-sdk/security).

## Как сообщить

Не открывайте публичный issue. Создайте приватный отчёт на странице
[Security → Report a vulnerability](https://github.com/expatriate/grafana-faro-wrapper/security/advisories/new) —
его видит только мейнтейнер. Опишите:

- версию пакета и способ подключения (ESM, CJS, `dist/index.umd.full.js`, `dist/index.umd.js`);
- шаги воспроизведения и что именно утекает или исполняется;
- по возможности — минимальный пример.

## Что будет дальше

Мейнтейнер подтвердит получение и оценит отчёт, обычно в течение недели. Если уязвимость подтвердится,
исправление выйдет патч-релизом, а в GitHub Security Advisory будут указаны затронутые версии и — если вы не
против — ваше имя.
